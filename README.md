# douyin-bot-desktop · 抖音 AI 好友助手桌面版

本项目是 [l0yce/douyin-bot](https://github.com/l0yce/douyin-bot) 的 **Windows 桌面版**，将抖音私信机器人、幕间剧情记忆系统和管理功能集成到桌面界面中。

你可以在自己的电脑上配置模型、导入抖音登录态、选择允许自动回复的好友，并管理聊天动态、剧情、记忆和运行日志。日常使用无需部署 Linux 服务器。

仓库仅包含源码和公开示例，不包含开发者的账号、API Key、Cookies、私人角色设定、好友名单或聊天记录。使用时需要配置自己的账号和模型。

## 主要功能

- **好友白名单**：发现最近聊天中的好友，选择允许自动回复的对象；新发现的好友默认不启用。
- **模型与账号配置**：填写 OpenAI 兼容接口、模型名称、API Key、抖音账号和角色人设。
- **聊天动态与手动协作**：查看聊天动态，结合网页中实际读取到的上下文生成回复，支持人工接话。
- **剧情与记忆**：管理角色、剧情记录、记忆、关系与日程，以及聊天协作和视频评论相关设置。
- **服务管理与日志**：查看机器人、幕间引擎和本地面板的状态，启动或停止服务，检查运行日志。
- **桌面体验**：深浅主题、系统托盘、单实例运行，以及 Windows 安装包与卸载支持。

图片理解需要配置支持图片的模型。分享视频使用评论参考，不代表程序观看了视频画面或音频。抖音页面变化、登录验证和网页未加载的内容都可能影响读取与收发。

## 使用前准备

1. Windows 10/11 64 位电脑，已安装 Microsoft Edge 或 Google Chrome。
2. 自己有权使用、能够正常登录抖音网页版私信的账号。
3. 支持 OpenAI Chat Completions 的模型服务，包括接口地址、API Key 和模型名称。
4. 使用期间保持电脑联网、唤醒，并保持程序运行。

## 获取并打开程序

从 [Windows 桌面预览版下载页](https://github.com/l0yce/douyin-bot-desktop/releases/tag/v2026.10.12-preview.1) 下载 `DouyinBot-Setup.exe`（约 102 MB），运行安装包，从桌面或开始菜单打开“抖音 AI 好友助手”即可，无需另外安装 Python 和 Node.js。后续版本见 [Releases](https://github.com/l0yce/douyin-bot-desktop/releases)。

普通用户只需下载安装 EXE。`DouyinBot-Source.zip` 是对应安装包的构建源码，供开发者参考；`SHA256.txt` 用于校验下载文件。GitHub 的 **Code → Download ZIP** 和自动生成的 **Source code** 压缩包都是源码，不能直接当作安装包运行。

当前发布为预览版，已完成本机安装、重复安装、程序启动和卸载验证，其他电脑与真实账号收发仍需自行验证。安装包尚未代码签名。

安装包默认安装到当前用户的 `%LOCALAPPDATA%\Programs\DouyinBotDesktop`。安装或打开界面不会自动开始回复好友，需要完成以下配置后手动启动机器人。

## 首次使用

### 1. 填写模型与账号

打开左侧 **模型与账号**，填写并保存：

| 设置 | 填写内容 |
| --- | --- |
| 接口地址 | 模型服务商提供的 OpenAI 兼容地址，例如 `https://你的服务地址/v1` |
| API Key | 你自己的模型服务密钥 |
| 聊天模型 | 服务商提供的实际模型名称 |
| 抖音号、昵称 | 你自己的抖音账号信息，抖音号用于身份校验 |
| 角色人设 | 希望机器人采用的身份、说话方式和回复风格 |
| 视觉模型 | 可选；需要理解图片时填写支持图片的模型 |

修改配置前先停止机器人和幕间引擎。普通家庭网络通常不需要填写浏览器代理；需要代理时，在设置中填写你自己可用的代理地址。

### 2. 导入抖音登录态

1. 在浏览器中登录 [抖音网页版](https://www.douyin.com/)，确认能正常打开私信。
2. 使用 Cookie-Editor 等工具导出抖音网站的 Cookies JSON。
3. 返回程序的 **运行状态**，点击 **导入 Cookies** 选择 JSON 文件，或点击 **粘贴 Cookies** 粘贴完整内容。

导入后机器人仍保持停止。Cookies 属于账号登录凭据，请仅在自己的电脑中使用，不要发到 GitHub、社区帖子或他人的排错截图里。

### 3. 选择允许回复的好友

1. 保持机器人停止，进入 **好友白名单**。
2. 点击 **发现好友**，等待程序读取最近聊天；此过程可能打开浏览器，不会发送消息。
3. 勾选允许自动回复的好友，点击 **保存修改**。

发现好友不等于启用好友。只有已保存并启用的好友才进入自动回复范围；发现失败时先检查 Cookies 是否过期、浏览器是否正常。

### 4. 启动并确认效果

回到 **运行状态**，点击 **启动全部**。也可按需启动单个服务，程序会检查配置并协调相关依赖服务。

先用一位测试好友发送消息，在 **聊天动态** 和 **日志中心** 查看处理情况，再到抖音中确认实际收发。模型请求会使用你配置的服务，其费用按服务商规则计算。

### 5. 管理剧情、记忆和日常运行

- 在 **剧情与记忆** 中管理角色、剧情、记忆、关系和日程，按需调整聊天协作及视频评论设置。
- 在 **日志中心** 检查连接、模型请求和运行异常。
- 点击窗口关闭按钮会缩到系统托盘，服务仍可继续运行。要完全退出，请右键托盘图标，选择 **退出**。
- 程序退出、电脑关机或休眠后，机器人无法继续回复。

## 数据、更新与卸载

个人配置、登录态、记忆数据库和日志默认保存在：

```text
%APPDATA%\douyin-bot
```

可以在资源管理器地址栏粘贴此路径打开。备份前请先从托盘完全退出程序，再复制整个数据目录。原项目服务器上的配置和记忆不会自动同步到桌面版。

使用安装包更新或卸载前，先从托盘完全退出。安装包升级和卸载会保留上述个人数据；若要彻底清除，请自行备份后处理该目录。

## 常见问题

**启动失败或提示端口占用**：检查是否已有本程序或原项目在运行。本地面板、内部控制和幕间引擎分别使用 `8790`、`8791`、`18765` 端口。

**发现好友失败或机器人无法登录**：先在正常浏览器中确认抖音账号可用，重新导入 Cookies，并检查 Edge/Chrome 和代理设置。

**机器人不回复**：确认模型地址、密钥和模型名有效，抖音号已填写，好友已启用并保存，相关服务已启动，再查看日志。

**提示有待确认发送**：先停止机器人和幕间引擎，在抖音中核对实际聊天记录，再使用运行状态页的 **核对待确认发送** 处理。程序不会通过该操作重发原回复。

**与原项目有什么区别**：原项目提供服务器部署及网页管理方式；本仓库提供 Windows 桌面界面和本地进程管理。原项目的 Linux/systemd 部署、服务器开机运行和独立邮件故障定时检测不属于本桌面版已完成的使用流程。

## 从源码运行

准备 Python 3.12、Node.js 22 或更高版本及 npm、Git，然后在 PowerShell 中执行：

```powershell
git clone https://github.com/l0yce/douyin-bot-desktop.git
cd douyin-bot-desktop
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -r backend/douyin-friend-ai-bot/requirements.txt
cd backend/douyin-interlude
npm ci
npm run build
cd ../..
.\.venv\Scripts\python.exe main.py
```

源码运行同样使用系统 Edge/Chrome，无需额外下载 Playwright 浏览器。开发时可用环境变量 `DOUYIN_DESKTOP_DATA_DIR` 指定独立数据目录，避免与日常使用的数据混用。

## 构建安装包

完成源码运行环境准备后，安装 Inno Setup 7，在项目根目录执行以下命令，并将路径替换为自己的 `ISCC.exe` 路径：

```powershell
.\.venv\Scripts\python.exe build.py --iscc "C:\你的安装路径\Inno Setup 7\ISCC.exe"
```

构建需要联网下载内嵌 Python/Node 并安装依赖。中间程序目录位于 `build/payload/douyin-bot-desktop`，最终安装包输出到 `release`。分享安装包时只需发送生成的 Setup.exe，无需附带整个源码目录。
